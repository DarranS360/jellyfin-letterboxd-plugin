Letterboxd Collections

Automatically creates and refreshes Jellyfin collections from a Letterboxd user's public lists and watchlist, on Jellyfin's own scheduled task runner.

The public Letterboxd profile to sync from, e.g. "darrans360".
Creates a "<username> Watchlist" collection alongside your named lists.
Scans the user's public lists page and creates/updates a collection for every list found - new lists show up automatically.
List slugs to skip during auto-discovery, e.g. "watched,diary-2025". Find a slug in the list's URL: letterboxd.com/username/list/<slug>/
When on, each sync fully matches the collection to the current list contents (adds and removes). When off, films are only ever added.
Builds a poster-strip cover image for collections that don't already have one. Never overwrites a manually-set image.
