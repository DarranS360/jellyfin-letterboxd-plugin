Letterboxd Collections

Automatically creates and refreshes Jellyfin playlists or collections from a Letterboxd user's public lists and watchlist, on Jellyfin's own scheduled task runner.

The public Letterboxd profile to sync from, e.g. "cinephile42".
Playlists are ordered and owned by a specific user. Collections are library-wide with no owner.
The Jellyfin user who will own created playlists.
When off, only the owner above can see the created playlists.
Creates a "<username> Watchlist" playlist/collection alongside your named lists.
Scans the user's public lists page and creates/updates an entry for every list found - new lists show up automatically.
List slugs to skip during auto-discovery, e.g. "watched,diary-2025". Find a slug in the list's URL: letterboxd.com/username/list/<slug>/
When on, each sync fully matches the playlist/collection to the current list contents (adds and removes). When off, films are only ever added.
Builds a poster-strip cover image for playlists/collections that don't already have one. Never overwrites a manually-set image.
